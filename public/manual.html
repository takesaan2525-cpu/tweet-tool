① これは何の仕事？

メンズエステ・夜職の店舗に、業務を自動化するツールを売る仕事です。

店舗は「毎日の掲載サイト更新・予約管理・LINE対応・給与計算」など、めんどくさい作業に追われています。それをまるごと自動化するシステムを、買い切り40,000円（他社は月3万〜）で提供します。

売るもの

  • 専用予約サイト＋ダブルブッキング防止
  • 予約確定→キャストへのLINE自動通知
  • お客様への自動予約確認
  • 掲載サイト（エステラブ・エステ魂等）の自動更新でランキング維持
  • 給与・指名の自動集計
強み：競合「ベンリー」は月3万円の掲載更新だけ。うちは買い切り・全部入り・店舗専用カスタムで殴ります。

③ ツールの使い方

画面下に2つのタブがあります。

📋 「DM・投稿」タブ ＝ 営業文のコピペ集

  1. 上のカテゴリ（ツール営業／DM 等）を選ぶ
  2. 送りたいテンプレをタップすると本文が開く
  3. 「コピーしてDMに貼り付ける」を押す
  4. Instagram・X・LINEのDM欄に貼って送信

テンプレは「営業の流れ順」に並んでいます（上から順に使えばOK）。

📒 「リスト」タブ ＝ 送る相手の管理

  • CSVインポート：集めた店舗リスト（CSV）を読み込む
  • 検索：店名・エリア（例「デリヘル」「大阪」）で絞り込み
  • ステータス管理：各相手を「未送信／送信済み／返信あり／成約／断られた」で管理
  • 一括削除：キーワードでまとめて削除
基本動作：リストで未送信の相手を開く → DMタブでテンプレをコピー → 送る → ステータスを「送信済み」に変える。これの繰り返し。

④ 営業の全体フロー

段階やること使うテンプレ
1. 初回DM相手に合う紹介文を送るメンエス向け／デリヘル向け 等
2. 返信が来た状況をヒアリングするヒアリング項目
3. 興味あり電話・通話に誘導電話誘導／電話トーク台本
4. 迷ってる本音を聞く・追わない「検討します」への返し
5. 保留次回フォローの約束次回フォロー／2日後の追いDM
6. 契約見積書・ヒアリングシート送付制作ヒアリングシート
最重要ルール：料金や全機能を文字で一気に出さない。電話で話すために取っておく。文字で全部出すと「検討します」で終わります。

⑤ テンプレの使い分け

  • 相手がメンエス店舗 → 「メンエス向け（短文/詳細）」
  • 個人セラピスト → 「メンエス個人セラピスト向け」
  • デリヘル・派遣型 → 「デリヘル店舗向け」
  • 返信きた → 「ヒアリング項目」
  • 興味ありそう → 「電話誘導」
  • 「検討します」 → 「検討します への返し」（本音を聞く）

迷ったら「短文版」から。長文は重く感じられて読まれにくい。

⑥ 送信のコツ（時間帯・件数）

時間帯評価理由
13〜16時◎ 最強店舗が起きて出勤準備の余裕タイム
24〜26時◯営業終わりで手が空く
朝（7〜11時）✕夜職は寝てる時間
  • 1日20〜30件を目安に。一気に大量送信しない。
  • X（旧Twitter）は短時間の連投で凍結リスク。15〜20分に1通ペースが安全。
  • 同じ文の連投もNG判定されやすい → テンプレを何種類か回す。

⑦ 返信が来たあとの進め方

鉄則1：説明しすぎない、質問で返す

「今いちばん手間な作業は何ですか？」と聞いて、相手に課題を話させる。

鉄則2：「検討します」で引かない

お礼で終わらせず「ひっかかってる点は費用・手間・効果のどれですか？」と本音を聞く。ここで止めると二度と進みません。

鉄則3：通話に持ち込む

「画面お見せしながら10分だけ」で電話に誘導。通話できたら成約率が一気に上がる。

大阪など特有の注意：「AIっぽい・ロボットっぽい返信」は嫌われます。完璧な敬語の長文より、短め＋絵文字＋相手の言葉を拾う。「それ大変ですよね😊」と共感を挟むと一気に人間味が出ます。

⑧ 契約が取れたら

  1. 見積書・提案書を送る（PDFは小林が用意）
  2. 制作ヒアリングシートを記入してもらう（ツールのテンプレにあり）
  3. 公式LINEは必ず店舗（お客様）名義で作る。作れない場合はこちらで作り、店舗を管理者に追加する。
  4. 必要な技術情報（掲載サイトの管理画面ログイン等）を集める
  5. 制作・連携は小林が担当
お金のルール：口約束で着手しない。前金（半額）をもらってから作り始める。要望は最初に決めた範囲（スコープ）まで。

⑨ やってはいけないこと

  • ❌ 「ランキング1位にします」と断言 → 「更新順の上位を維持」と正直に言う
  • ❌ 料金・全機能を初回DMで全部出す → 電話に取っておく
  • ❌ パスワード（2928）やツールを外部に共有
  • ❌ 公式LINEを自分名義のまま放置（顧客データは店舗のもの）
  • ❌ 大量連投で凍結 → ペースを守る
  • ❌ 違法・無届けの店との取引（届出済みの店だけ）

⑩ 報酬について

成功報酬型

1件の案件を最初から最後まで（契約 → 制作 → 納品・完了）すべて終えたら、

1件につき 15,000円

支払いの条件

  • 担当した案件が「完結」＝契約成立し、制作・納品まで終わって、店舗からの入金が確認できた時点
  • 途中で止まった・キャンセルになった案件は対象外

イメージ

状況報酬
DM送って返信もらった—（まだ）
契約は取れたが制作・入金が未完—（完結待ち）
契約 → 納品 → 入金まで完了15,000円
つまり：動いた分だけじゃなく「ちゃんと1件カタチにした」ら報酬。数をこなせばそのまま積み上がります。

※ 金額・条件は状況に応じて相談のうえ変更する場合があります。
